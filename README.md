# TradeMate Pro

A professional network app for UK tradespeople. Find work, build a trusted network, trade materials and tools, and support others in the trade, all in one place.

![TradeMate Pro](trademate-pro.png)

Live site: https://trademate-pro-website.vercel.app

## What it does
TradeMate Pro connects verified UK tradespeople so they can find work, grow a reliable network, and help each other. Members are identity verified, and the platform covers a wide range of trades.

## My role
I built the product across web and mobile: the Next.js marketing site, a React Native mobile app, an admin dashboard, and the backend APIs.

## Tech
Next.js, React, Tailwind CSS, React Native, Node.js.
